# Contributing

## Task Traceability

Every change must map to a Corporate Website implementation task using a `CW-###` identifier.

## Branches

Use one of:

- `feature/CW-###-short-name`
- `fix/CW-###-short-name`
- `chore/CW-###-short-name`
- `security/CW-###-short-name`
- `docs/CW-###-short-name`

## Commits

Use `<type>(CW-###): concise change description`.

## Pull Requests

PRs must document scope, affected RTM requirements, ADR references, tests, security/privacy considerations, migrations, deployment implications, rollback/forward-recovery considerations, and any required human gate.

## Quality

Do not commit secrets. Do not bypass required CI, review, security, testing, or production authorization controls.
